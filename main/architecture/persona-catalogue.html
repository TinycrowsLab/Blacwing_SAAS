Persona catalogue

What each agent persona may do. The definitions in packages/agents/src/personas are the source; this page is regenerated from them and CI fails when it is stale. Tenant overrides (effort, turns, budget and standard-tier lowering) change the effective values of one tenant only; see GET /v1/personas for those.

orchestrator

  • Mandate: Drive the approved run to completion: read the shared task listing, delegate open subtasks to the right specialist persona, track test-case status, request mentor review on stalls and decide completion. Never interacts with targets directly.
  • Model tier: deep → claude-opus-5-5 (Anthropic provider; Bedrock adds the anthropic. prefix)
  • Effort: high; max turns: 200; default budget: $25
  • Intrusiveness ceiling: passive; submission required: no
  • Prompt version: 1.0.0
  • Allowed tools: mcp__blackwing_engagement__get_engagement_state, mcp__blackwing_engagement__list_open_subtasks, mcp__blackwing_engagement__dispatch_subtask, mcp__blackwing_engagement__get_subtask_result, mcp__blackwing_engagement__request_mentor_review, mcp__blackwing_engagement__mark_test_case_status, mcp__blackwing_engagement__request_scope_exception
  • Disallowed tools: Bash, WebFetch, WebSearch, Agent, mcp__blackwing__http_request
  • Declared oracle types: none
  • Inputs: engagement_state, open_subtasks, subtask_results, approved_envelope, surface_model_summary
  • Helpers: none

planner

  • Mandate: Convert the surface model into proposed test_cases. Each carries an intrusiveness class, a request budget, a declared validation oracle, OWASP/WSTG/ASVS references, and target endpoints and roles. Cite standard IDs only; never write payloads. Design oracles; never run them.
  • Model tier: deep → claude-opus-5-5 (Anthropic provider; Bedrock adds the anthropic. prefix)
  • Effort: high; max turns: 40; default budget: $5
  • Intrusiveness ceiling: state_changing; submission required: no
  • Prompt version: 1.0.0
  • Allowed tools: mcp__blackwing_surface__surface_query, mcp__blackwing_testcases__test_case_library_read
  • Disallowed tools: Bash, WebFetch, WebSearch, Agent, mcp__blackwing__http_request, mcp__blackwing__tcp_probe
  • Declared oracle types: reflected_marker, status_diff, timing_with_baseline, out_of_band, access_matrix, error_signature, file_read, header_flag
  • Inputs: surface_model, recon_summary, test_case_library, run_envelope
  • Helpers: none

  • Model tier: standard → claude-opus-5-5 (Anthropic provider; Bedrock adds the anthropic. prefix)
  • Effort: medium; max turns: 20; default budget: $2
  • Intrusiveness ceiling: state_changing; submission required: no
  • Prompt version: 1.0.0

  • Declared oracle types: reflected_marker, status_diff, timing_with_baseline, out_of_band, access_matrix, error_signature, file_read, header_flag

  • Helpers: none

web-api-specialist

  • Mandate: Detect injection (CWE-89, CWE-79, WSTG-INPV-05/01/02), SSRF (CWE-918, WSTG-INPV-19, API7), XXE (CWE-611, WSTG-INPV-07), SSTI (CWE-1336, WSTG-INPV-18), path traversal (CWE-22, WSTG-ATHZ-01), CORS and headers (WSTG-CLNT-07, WSTG-CONF), GraphQL (WSTG-APIT), mass assignment (API3, CWE-915) and safe file-upload handling (WSTG-BUSL-09) using benign detection probes only, and submit each candidate bound to its oracle.
  • Model tier: deep → claude-opus-5-5 (Anthropic provider; Bedrock adds the anthropic. prefix)
  • Effort: high; max turns: 80; default budget: $10
  • Intrusiveness ceiling: active_safe; submission required: yes

  • Declared oracle types: reflected_marker, status_diff, out_of_band, error_signature, header_flag
  • Inputs: test_case_brief, surface_model, prior_subtask_results
  • Helpers: payload-crafter (tier fast, tools none): Builds benign detection probes for one declared class from the test-case brief. Returns data only; sends nothing.; response-differ (tier fast, tools none): Compares a probe response with its baseline and negative control and reports status, length, header and marker differences.
