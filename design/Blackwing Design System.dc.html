Brand Colours, remapped for a safety tool

On the website red is the main brand colour. Here it is used only for the Kill button, the Killed state and the logo. If Save and Kill were the same colour, people would stop noticing it.

Navy #004777 moves up to primary for actions, links, focus and running states. Ink #16171d is the text colour in light theme and the surface colour in dark.

04

Type: Poppins, as on tinycrows.com

{{ t.name }}{{ t.spec }}
{{ t.sample }}

Poppins is geometric and wide. In dense tables it runs at 13px with weight 400 for data and 500 for row titles. Headings use 600, as on the website.

JetBrains Mono is used only where characters have to be exact: IDs, hashes, HTTP, CVSS vectors and code.

One word in each page heading is set in brand red, the same way the site does it. Inside the console this only happens on sign-in, empty states and report covers.
